# Theme19 — Priangan

Sundanese-inspired invitation in forest green, ivory and muted gold. All theme styling uses Tailwind; shared colors are `sunda-*` tokens in `src/app/globals.css`. No CSS module is used.

Assets generated with built-in ImageGen, optimized as WebP; the siger ornament preserves transparency. These are artistic interpretations rather than reproductions of ceremonial objects.

## Generation prompts

### `priangan.webp`

Portrait 2:3 fine watercolor illustration for a Sundanese West Java wedding invitation. Quiet misty Parahyangan mountains, layered pale sage hills, a small traditional Sundanese raised bamboo house with julang ngapak roof in the LOWER third, delicate bamboo foliage and white jasmine blossoms framing only the lower corners. Upper 65 percent is warm ivory handmade paper, mostly clean negative space. Fine muted olive and deep forest-green botanical linework, tiny antique gold details, airy romantic editorial wedding stationery. Authentic West Java inspiration, not Javanese joglo, no wayang or gunungan. No people, no text, no logo or watermark. Flat painted artwork.

### `siger-melati.webp`

Transparent standalone ornamental arrangement for a Sundanese West Java wedding invitation: a refined Sundanese bridal siger tiara in antique gold with delicate pointed curving filigree, resting among creamy white jasmine blossoms and fine green bamboo leaves; graceful jasmine strands draping a little to the sides. Elegant fine watercolor and hand-engraved gold details, muted natural greens, ivory petals, heirloom wedding stationery. Wide balanced symmetrical arrangement, fully visible with generous transparent margins. Genuine alpha transparent background. No text, no human head or face, no frame, no watermark.

## Usage

Select/register `Theme19` through the existing admin theme management. The dynamic theme loader resolves `theme19.tsx`; desktop decoration is included. No database records are created by this change.

Includes cover/content crossfade, scroll reveals, floating ornament, reduced-motion handling, countdown, couple portraits, events, map/stream links, stories, gallery, RSVP, wishes, music, gifts and guest QR.
